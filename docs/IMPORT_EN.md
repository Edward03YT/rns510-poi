# RNS 510 Personal POI Import Guide (English)

This guide explains how to import `.asc` POI (Points of Interest) packages generated by **rns510-poi-forge** onto your Volkswagen **RNS 510** (or Škoda Columbus / SEAT Media System) navigation unit.

---

## 1. Requirements

- A vehicle equipped with a **Volkswagen RNS 510**, **Škoda Columbus**, or **SEAT Media System** head unit.
- An **SD or SDHC memory card** (formatted as **FAT32**, maximum capacity 32 GB recommended).
  > [!TIP]
  > MicroSD cards in standard SD adapters work fine, provided they are formatted in FAT32 (4096-byte allocation unit size).
- Ready `.asc` POI files downloaded from the releases page, generated locally, or packaged as a ZIP.

---

## 2. Preparing the SD Card

1. **Format the SD card:** Ensure the card is freshly formatted in **FAT32**.
2. **Directory Structure:** Depending on the firmware version, the RNS 510 reads files either from the SD card root or from a dedicated folder:
   - Recommended: Create a folder named `PersonalPOI` in the root of the SD card:
     ```
     SD:\
     ├── PersonalPOI\
     │   ├── romania_fuel_001.asc
     │   ├── romania_ev_charging_001.asc
     │   └── romania_pharmacy_001.asc
     └── ATTRIBUTION.txt
     ```
   - If the unit does not find the files inside `/PersonalPOI/`, copy the `.asc` files directly into the SD card root (`SD:\romania_fuel_001.asc`).

---

## 3. Step-by-Step Import on the Head Unit

1. **Power on** the RNS 510 unit (turn on vehicle ignition).
2. **Insert the SD card** into the front slot below the display.
3. Press the physical **NAV** (Navigation) button.
4. Press the **Setup** hardware button or touch the **Settings** gear icon on the screen.
5. In the Navigation settings menu, select:
   - **Navigation**
   - **My special destinations (Personal POI)**
   - **Import**
   - **Import into database**
6. The unit will scan the SD card, read the `.asc` files, and prompt you to confirm the import into the internal hard drive (HDD) database.
7. Confirm the import and wait for the progress bar to finish.

---

## 4. Displaying POIs on the Navigation Map

After a successful import, enable your new destinations on the map view:

1. Press **NAV** to return to the map.
2. Touch the **Map Setup** or **Extras** on-screen icon.
3. Tap **Select POI categories to display** (Select special destinations).
4. Scroll down to your newly imported personal categories (e.g. *Fuel Stations*, *EV Charging*, *Pharmacies*) and tick the checkboxes.
5. Return to the map. Pins will now appear along your routes!

---

## 5. Troubleshooting

| Issue | Potential Cause | Solution |
|---|---|---|
| "No data found on SD card" | Incorrect folder or file format | Test placing `.asc` files in `SD:\PersonalPOI\` or directly in `SD:\`. Ensure SD card is FAT32. |
| SD card not recognized | Card capacity > 32GB or exFAT format | Use an SDHC card <= 32GB formatted as FAT32. |
| Pins appear in ocean/Africa | Inverted coordinates | Run `poi-forge probe-file --generate-matrix` and verify coordinate order per `docs/FORMAT_PROBE.md`. |
| Romanian diacritics corrupted | Unsupported encoding on unit | Use default `ascii_transliterate: true` in `config/format.yml` to safely display plain Latin characters. |
| Import dialog freezes | File too large or too many POIs | The writer automatically chunks files at 5,000 POIs. If your unit is on older firmware, lower `max_pois_per_file` to 2,000. |
